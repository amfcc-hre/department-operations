The three statuses

StatusWhat the record says
MonitoringThe clinic is following up the student's condition. This status does not itself allow bed rest.
Bed Rest AllowedThe student has been allowed bed rest. The existing attendance and student-status views also show bed-rest permission.
Referring to MDHThe clinic has recorded a referral to MDH. Record the referral and follow-up summary in the notes.

Each student has one active clinic status at a time. When staff change it, the previous status is retained in Closed records.

Clinic staff instructions

1 Open the register

  1. Open the Department Operations platform.
  2. Choose Department, select Clinic and enter the existing clinic PIN.
  3. The Clinic register opens first. Use Refresh register for the latest records.

2 Record a student

  1. Select Find a student.
  2. Search by name or registration number using at least two letters or digits.
  3. Select the student and confirm the name and registration.
  4. Choose one of the three statuses, enter the Condition and write a short Condition summary.
  5. Select Save status. Check the student's card in the register.

3 Find and export a list

  1. Choose the Status and Condition. Add a class-year filter or search text if needed.
  2. Check the number of records shown and read the summaries on the cards.
  3. Select Export filtered CSV for Excel or Google Sheets.
  4. Select Print / Save PDF to print the displayed list or choose Save as PDF in the browser's print window.

4 Update or close a record

  1. Choose Edit status and summary on the student's card.
  2. Update the status, condition or summary and select Save status.
  3. When the active clinic record should end, select Close record and confirm.
  4. Choose Closed records in the Records filter to review or export earlier records.

Use a consistent condition label so matching students appear together. You can select an existing label suggested by the Condition field. If assessment is pending, record that accurately instead of guessing a diagnosis.

School Administration instructions

  1. Open the School Administration Dashboard and sign in using the existing administrator password.
  2. Select the new Clinic register tab.
  3. Review the three status totals and the visible condition summaries.
  4. Filter by status, condition, class year or search text. Select Closed records when reviewing history.
  5. Choose Export filtered CSV or Print / Save PDF to export the displayed records.

The administrator workspace in Department Operations also has a Clinic register tab. Changes to a student's clinic status are made in the Clinic staff workspace.

The detailed register is available to Clinic staff and School Administration. Management, Student Leadership and Class Monitors retain the existing bed-rest status view.

Common problems

I cannot find a student

Clear the search, try the registration number or a different part of the name and use at least two characters. Only active students appear. Ask School Administration to check the student record if it is still missing.

A record is missing from the list

Select Clear filters, confirm Records is set to the correct list and select Refresh register. A closed or previous status is under Closed records.

My export button is disabled

The list may be loading, unavailable or empty. Clear the filters or refresh and check the number of records shown.

The record changed while I was editing

Another staff member may have updated it. Cancel, refresh the register, open the student's latest record and apply the intended change again.

Save status does not complete

Check that both Condition and Condition summary are filled in. Check the connection and read the message beside the form. Cancel or sign in again if the session has expired.

The print window does not open

Allow pop-ups for the AMFCC site and select Print / Save PDF again. In the print window choose a printer or Save as PDF.

The old bed-rest-only screen is still showing

Refresh the page. If needed, close and reopen the tab or use a hard refresh. Confirm you opened the current platform link.
